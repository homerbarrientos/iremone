# IREMS ONE Presentation

Standalone presentation/demo copy of IREMS ONE Property Birth.

## Run

Use Node.js 22 or newer, then `npm install` and `npm run dev`.

## Deploy to Vercel

Import homerbarrientos/iremone. Framework: Next.js. Root directory: repository root. Build: npm run build.

This copy preserves the original demo interface and data. It does not connect to the live IREMS UAT database, migrate records, or retain ChatGPT hosting authentication.
